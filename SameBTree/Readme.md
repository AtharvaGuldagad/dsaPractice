# Same Tree

## Intuition

### Simultaneous Structure and Value Matching

Two binary trees are considered identical if and only if they are structurally matching and all corresponding nodes have the exact same values.

Since binary trees are recursive data structures, we can verify this property by checking the current pair of nodes and then recursively delegating the same check to their left and right subtrees:

1. **Both nodes are null:** We've reached the bottom of both branches at the same time without finding any discrepancies—this path matches.
2. **One node is null while the other is not:** The trees have structural differences—they cannot be identical.
3. **Both nodes exist:** Compare their values. If the values match, recursively verify that both the left subtrees and right subtrees are identical.

---

## Step-by-Step Guide

1. **Check Base Cases:**
* If both `p` and `q` are `null`, return `true` (empty subtrees are identical).
* If only one of `p` or `q` is `null` (or their values don't match), return `false`.


2. **Value Comparison & Recursive Step:**
* If both nodes exist and `p.val == q.val`, check the subtrees.
* Recursively call `isSameTree(p.left, q.left)` to confirm the left branches are identical.
* Recursively call `isSameTree(p.right, q.right)` to confirm the right branches are identical.


3. **Combine Results:**
* Return `true` only if **both** the left and right subtree comparisons return `true`. Otherwise, return `false`.



---

## Complexity Analysis

* **Time Complexity:** $O(N)$
* Where $N$ is the total number of nodes in the smaller tree. In the worst-case scenario (when the trees are identical or differ only at the leaves), we visit every node up to $N$ times. At each node, basic conditional checks take $O(1)$ constant time.


* **Space Complexity:** $O(H)$
* The auxiliary space is determined by the call stack generated by the recursive calls, where $H$ is the height of the tree.
* In the worst-case scenario (a completely skewed tree like a linked list), $H = N$, giving $O(N)$ space.
* In the best-case scenario (a balanced tree), $H = \log N$, giving $O(\log N)$ space complexity.
