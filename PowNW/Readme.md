# Pow(x, n)

## Intuition

### Divide and Conquer (Binary Exponentiation)

Calculating $x^n$ by multiplying $x$ repeatedly $n$ times takes $O(n)$ linear time, which is too slow for large powers like $n = 2^{31} - 1$.

Instead, we use **Binary Exponentiation** (also known as Exponentiation by Squaring), which cuts the exponent in half at every step:

* **Even Exponents:** $x^n = (x^{n/2})^2$
* **Odd Exponents:** $x^n = x \times (x^{n/2})^2$

By computing the sub-problem $x^{n/2}$ only **once** and squaring its result (`hf * hf`), we reduce the required operations from $O(n)$ down to logarithmic time $O(\log n)$.

---

### Handling Integer Overflow and Negative Exponents

1. **Handling Negative $n$:** $x^{-n} = \frac{1}{x^n}$. We compute $x^{\vert{}n\vert{}}$ first and return $\frac{1}{\text{result}}$ at the end if $n < 0$.
2. **Handling `Integer.MIN_VALUE`:** In Java, 32-bit signed integers range from $-2147483648$ to $2147483647$. If $n = -2147483648$, performing `Math.abs(n)` directly as an `int` causes integer overflow because $2147483648$ exceeds `Integer.MAX_VALUE`. Your code correctly handles this edge case by casting $n$ to a 64-bit `long` before applying `Math.abs`: `Math.abs((long) n)`.

---

## Step-by-Step Guide

1. **Initial Edge Cases:**
* If $x == 0$, return `0`.
* If $n == 0$, return `1`.


2. Cast $n$ to `long` and take its absolute value: `long N = Math.abs((long) n)`.
3. Pass $x$ and $N$ to the recursive helper function `rec`:
* **Base Case:** If $N == 0$, return `1`.
* **Divide:** Compute `hf = rec(x, N / 2)`.
* **Conquer:**
* If $N$ is **even**, return `hf * hf`.
* If $N$ is **odd**, return `x * hf * hf`.




4. After `rec` computes the result for $x^{\vert{}n\vert{}}$:
* If original $n \ge 0$, return `res`.
* If original $n < 0$, return `1 / res`.



---

## Complexity Analysis

* **Time Complexity:** $O(\log n)$
* At each recursive step, the exponent $n$ is halved ($n / 2$). The total depth of the recursion tree is bounded by $\log_2(n)$. Because every level executes $O(1)$ multiplication operations, the runtime scales logarithmically.


* **Space Complexity:** $O(\log n)$
* The auxiliary space is determined by the call stack depth generated by recursion, which matches the maximum depth $\log_2(n)$.
* *(Note: An iterative loop approach using bit manipulation can reduce the auxiliary space to $O(1)$).*
