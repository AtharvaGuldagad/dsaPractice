# Count Good Nodes in Binary Tree

## Intuition

### Path-Maximum Tracking via Pre-Order DFS

A node in a binary tree is considered **good** if, on the path from the root to that node, there are no nodes with a value strictly greater than the current node's value.

Instead of walking back up to the root to check previous values for every node—which would take $O(N^2)$ time—we can pass the **maximum value seen so far along the current path** (`maxVal`) down during a Depth-First Search (DFS) traversal:

1. **Evaluate Current Node:** If `node.val >= maxVal`, then no ancestor node on this path was strictly greater. The current node is a "good node" (`res = 1`). Otherwise, it is not (`res = 0`).
2. **Update Path Maximum:** Before stepping down to child nodes, update the running path maximum: `maxVal = Math.max(node.val, maxVal)`.
3. **Propagate:** Pass this updated `maxVal` down to both the left and right subtrees and accumulate the total count.

---

## Step-by-Step Guide

1. Start the recursive traversal by calling `dfs(root, root.val)`. The initial path maximum is set to the value of the root node itself.
2. **Base Case Check:** If `node == null`, return `0` because an empty node contributes zero to the good node count.
3. **Good Node Verification:**
* Compare `node.val` against `maxVal`.
* If `node.val >= maxVal`, set `res = 1`; otherwise, set `res = 0`.


4. **Update Path Maximum:**
* Compute `maxVal = Math.max(node.val, maxVal)`.


5. **Recursive Exploration:**
* Recursively search the left subtree with the updated maximum: `dfs(node.left, maxVal)`.
* Recursively search the right subtree with the updated maximum: `dfs(node.right, maxVal)`.


6. **Combine and Return:**
* Sum `res` with the results from the left and right subtrees and return the total count back up to the parent caller.



---

## Complexity Analysis

* **Time Complexity:** $O(N)$
* We visit every node in the binary tree of size $N$ exactly once. At each node, evaluating the condition and updating `maxVal` takes $O(1)$ constant-time operations. Thus, total execution time scales strictly linearly with $N$.


* **Space Complexity:** $O(H)$
* The auxiliary space is determined by the maximum depth of the call stack generated by recursion, where $H$ is the height of the tree.
* **Balanced Tree:** $H = O(\log N)$ space.
* **Skewed Tree (Worst-Case):** $H = O(N)$ space.
