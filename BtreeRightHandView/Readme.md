# Binary Tree Right Side View

## Intuition

### Right-First Depth-First Search (DFS)

Imagine standing on the right side of a binary tree: at each horizontal depth level, you can only see the rightmost node. Any node sitting behind it on the left is obscured from your view.

Instead of performing a full Level-Order Traversal (BFS) with a queue, we can solve this using a modified **Depth-First Search (DFS)**:

1. **Prioritize the Right Subtree:** By visiting `node.right` before `node.left`, our search naturally reaches the rightmost path of the tree first at every single level.
2. **Track Visited Levels with Result Size:** We pass a `depth` variable down our recursive calls. Whenever `res.size() == depth`, it means we are stepping into this specific level for the very first time. Because our search prioritizes right children, the first node to reach any depth is guaranteed to be the rightmost visible node for that level. Any subsequent nodes visited at that same depth are ignored.

---

## Step-by-Step Guide

1. Create a list `res` to hold the visible node values from top to bottom.
2. Call the recursive helper function `dfs` starting at the `root` node with an initial `depth` of `0`.
3. **Base Case Check:** If `node == null`, return immediately.
4. **Visibility Check:**
* Compare `res.size()` with `depth`.
* If `res.size() == depth`, append `node.val` to `res`. (This captures the rightmost node for this level).


5. **Right-First Exploration:**
* Recursively visit the right child first: `dfs(node.right, depth + 1)`.
* Recursively visit the left child second: `dfs(node.left, depth + 1)`.


6. Return `res` once the recursive stack completes.

---

## Complexity Analysis

* **Time Complexity:** $O(N)$
* We visit every node in the binary tree of size $N$ at most once. Checking `res.size() == depth` and adding values takes $O(1)$ constant time per node, yielding linear time overall.


* **Space Complexity:** $O(H)$
* The auxiliary space is determined by the call stack generated by recursion, where $H$ is the height of the tree.
* **Balanced Tree:** $H = O(\log N)$ space.
* **Skewed Tree (Worst-Case):** $H = O(N)$ space.
* *(Note: The output list `res` requires $O(H)$ space to store one node per level).*
