# Validate Binary Search Tree

## Intuition

### Boundary Validation via Depth-First Search (DFS)

A binary tree is a valid Binary Search Tree (BST) if and only if **every node** in the left subtree is strictly less than the root, and **every node** in the right subtree is strictly greater than the root.

Checking only immediate children (e.g., `node.left.val < node.val`) is a common pitfall because it fails to catch invalid nodes deeper down the tree. Instead, every node must satisfy a global valid range $(\text{leftBoundary}, \text{rightBoundary})$ inherited from all of its ancestor decisions.

---

### Critical Bug in Fixed Min/Max Values

Hardcoding arbitrary numbers like `-1000000000` and `1000000000` breaks edge cases when tree nodes contain extreme 32-bit values such as `Integer.MIN_VALUE` ($-2^{31}$) or `Integer.MAX_VALUE` ($2^{31} - 1$).

To safely support the full range of 32-bit signed integers:

1. **Option A (64-bit Longs):** Pass `Long.MIN_VALUE` and `Long.MAX_VALUE` down as parameters.
2. **Option B (Null Boundaries):** Pass `Integer` object wrappers set to `null` initially to represent unrestricted boundaries.

---

## Step-by-Step Guide

1. Start the recursive helper `dfs` at the root node, passing unrestricted boundaries (or 64-bit long limits `Long.MIN_VALUE` and `Long.MAX_VALUE`).
2. **Base Case Check:** If `node == null`, return `true` because an empty subtree is a valid BST.
3. **Boundary Verification:**
* Check if `node.val` falls strictly within $(\text{leftBoundary}, \text{rightBoundary})$.
* If `node.val <= leftBoundary` or `node.val >= rightBoundary`, return `false` immediately.


4. **Recursive Exploration:**
* **Going Left:** Update the upper limit. The left child must be strictly less than `node.val`, so pass `(leftBoundary, node.val)`.
* **Going Right:** Update the lower limit. The right child must be strictly greater than `node.val`, so pass `(node.val, rightBoundary)`.


5. Return `true` only if both recursive calls evaluate to `true`.

---

## Complexity Analysis

* **Time Complexity:** $O(N)$
* We visit every node in the binary tree of size $N$ at most once. At each node, comparing against range boundaries takes $O(1)$ constant time operations.


* **Space Complexity:** $O(H)$
* The auxiliary space is determined by the maximum call stack depth generated by recursion, where $H$ is the height of the tree.
* **Balanced Tree:** $H = O(\log N)$ space.
* **Skewed Tree (Worst-Case):** $H = O(N)$ space.
